# Task 2: Stock Portfolio Tracker

Calculates the total investment value of a stock portfolio using hardcoded prices.

## Features
- Enter stock symbols and quantities (repeated symbols are merged)
- Prices defined in a dictionary, e.g. `{"AAPL": 180, "TSLA": 250}`
- Displays a formatted table and total investment value
- Optionally saves the result to `portfolio.csv`

## Run
```bash
python portfolio_tracker.py
```

## Concepts Used
dictionary, input/output, basic arithmetic, file handling (CSV)
