# Task 1: Hangman Game

A text-based Hangman game. The computer picks a random word from a list of 5 words, and the player guesses one letter at a time.

## Rules
- 5 predefined words (no file or API needed)
- 6 incorrect guesses allowed
- Invalid input and repeated letters are rejected
- Console input/output only

## Run
```bash
python hangman.py
```

## Concepts Used
`random`, `while` loop, `if-else`, strings, lists
