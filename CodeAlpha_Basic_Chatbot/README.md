# Task 4: Basic Chatbot

A rule-based chatbot that responds to keywords such as "hello", "how are you", and "bye".

## Features
- Predefined keyword-to-reply rules
- Whole-word matching, so "hi" does not trigger on "this"
- Fallback reply for unknown input
- Type "bye" (or "goodbye") to exit

## Run
```bash
python chatbot.py
```

## Concepts Used
`if-elif` logic, functions, loops, input/output
