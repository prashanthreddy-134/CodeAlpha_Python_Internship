## 👨‍💻 About This Repository

Welcome to my **CodeAlpha Python Internship Repository**!

This repository contains four Python projects developed to strengthen my programming fundamentals, problem-solving abilities, automation skills, and understanding of application development.

Each project focuses on a practical use case and demonstrates how Python can be used to build interactive applications and automate everyday tasks.

## 🚀 Projects

### 01. 🎮 Hangman Game

A classic word-guessing game built using Python.

**Features**
- Random word selection.
- Interactive letter guessing.
- Tracks incorrect attempts.
- Displays remaining lives.
- Win and lose conditions.
- Replay functionality.

**Run the project:**

```bash
python CodeAlpha_Hangman_Game/hangman.py
```

---

### 02. 📈 Stock Portfolio Tracker

A command-line application that calculates the value of a stock investment portfolio.

**Features**
- Add stock symbols and quantities.
- Supports multiple predefined stocks.
- Calculates individual stock values.
- Calculates total portfolio value.
- Exports portfolio information to CSV.

**Run the project:**

```bash
python CodeAlpha_Stock_Portfolio_Tracker/portfolio_tracker.py
```

> Note: Stock prices are predefined demonstration values, not live market data.

---

### 03. ⚙️ Python Task Automation

A collection of automation utilities designed to reduce repetitive manual work.

**Features**

| Tool | Functionality |
|---|---|
| 🖼️ Image Organizer | Organizes JPG, JPEG, PNG, WEBP and other supported image formats. |
| 📧 Email Extractor | Extracts unique email addresses using regular expressions. |
| 🌐 Website Title Extractor | Retrieves webpage titles and saves them to text files. |

**Run the project:**

```bash
python CodeAlpha_Task_Automation/automation.py --help
```

**Example commands:**

```bash
python CodeAlpha_Task_Automation/automation.py jpg photos sorted_photos

python CodeAlpha_Task_Automation/automation.py emails contacts.txt emails_found.txt

python CodeAlpha_Task_Automation/automation.py title https://www.codealpha.tech title.txt
```

---

### 04. 🤖 Basic Rule-Based Chatbot

An interactive Python chatbot that responds to user messages using keyword matching and predefined conversational patterns.

**Features**
- Greeting and conversation handling.
- Multiple response variations.
- Python and programming discussions.
- Internship-related responses.
- Jokes and motivational messages.
- Help and exit commands.

**Run the project:**

```bash
python CodeAlpha_Basic_Chatbot/chatbot.py
```
