# CodeAlpha Python Internship Projects

A collection of Python projects developed as part of my CodeAlpha Python Internship.

## Projects

### 1. Hangman Game
- Interactive word-guessing game.
- Random word selection.
- Limited attempts and letter validation.
- Replay functionality.

### 2. Stock Portfolio Tracker
- Add stock symbols and quantities.
- Calculate individual stock values.
- Calculate total portfolio value.
- Export portfolio data to CSV.
- Uses predefined demonstration prices, not live market data.

### 3. Task Automation
A collection of three Python automation tools:
- **Image Organizer:** Organizes JPG, JPEG, PNG, WEBP and other supported image files.
- **Email Extractor:** Extracts unique email addresses using regular expressions.
- **Website Title Extractor:** Retrieves and saves webpage titles using Python URL handling and HTML parsing.

### 4. Basic Chatbot
- Rule-based conversational chatbot.
- Multiple conversation categories.
- Randomized responses.
- Keyword and pattern matching.
- Interactive terminal interface.

## Technologies Used
- Python 3
- Regular Expressions
- File Handling
- CSV
- HTML Parsing
- URL Handling
- Argparse

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/prashanthreddy-134/CodeAlpha_Python_Internship.git
   ```

2. Open the project folder:

   ```bash
   cd CodeAlpha_Python_Internship
   ```

3. Install Python 3.8 or above.

## Running the Projects

Run each project from the repository root:

```bash
python CodeAlpha_Hangman_Game/hangman.py

python CodeAlpha_Stock_Portfolio_Tracker/portfolio_tracker.py

python CodeAlpha_Task_Automation/automation.py --help

python CodeAlpha_Basic_Chatbot/chatbot.py
```
