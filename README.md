# CodeAlpha Python Programming Internship

Solutions for the CodeAlpha Python Programming tasks.

| # | Task | Folder | Run with |
|---|------|--------|----------|
| 1 | Hangman Game | `CodeAlpha_Hangman_Game/` | `python hangman.py` |
| 2 | Stock Portfolio Tracker | `CodeAlpha_Stock_Portfolio_Tracker/` | `python portfolio_tracker.py` |
| 3 | Task Automation with Python Scripts | `CodeAlpha_Task_Automation/` | `python automation.py --help` |
| 4 | Basic Rule-Based Chatbot | `CodeAlpha_Basic_Chatbot/` | `python chatbot.py` |

Each folder has its own README with details.

Requirements: Python 3.8+. Task 3's `title` command also needs `requests` (`pip install requests`).
